??? info "Know the Term: Evals"
    An **eval** (short for evaluation) is a repeatable test of how well an AI system does its job.
    You collect a set of realistic example inputs, write down what a good answer must contain or
    avoid, run the system on all of them, and score the results. Because AI output varies, you
    judge a system by its score across many examples, not by one impressive demo. Run the same
    eval before and after every change, such as a new prompt or a new model, and you can see
    whether the change helped or quietly broke something.

    **Analogy:** a driving test with a fixed route. Every candidate drives the same streets, so
    the results can be compared, and a good afternoon on an empty road does not count.

    **Why you care:** "it looked good when I tried it" is not evidence. Before trusting or buying
    an AI system, ask to see its evals: what was tested, how often it passed, and on which cases it
    failed.
