??? info "Know the Term: Skills"
    A **skill** is a packaged set of instructions, and sometimes files and small scripts, that an
    AI assistant loads only when a task needs it. "Write a SitRep in the Coalition template" could
    be a skill: a folder with the template, the style rules and a checklist. The assistant sees a
    one-line description of every available skill, and reads the full contents only when the
    description matches the job, so dozens of skills can be available without crowding its
    attention. Several assistants and agent frameworks support skills or something similar as of
    2026, under various names.

    **Analogy:** the binders on an office shelf. Nobody memorises every procedure; you read the
    spine, then open the right binder when the task comes up.

    **Why you care:** skills let a team capture "how we do this here" once and reuse it, instead
    of everyone pasting the same long instructions into every chat. Treat a skill like any shared
    procedure: someone owns it and keeps it current.
