??? info "Know the Term: “Vibe coding” vs spec-driven development"
    **Vibe coding** (a phrase coined in 2025) means building software by describing what you want
    to an AI, accepting whatever code it produces without reading it closely, and judging only
    whether the result *seems* to work. **Spec-driven development** starts from a short written
    specification (what the software must do, what it must never do, and how you will check),
    turns that into tests, and then lets the AI write code that must pass those tests, which a
    person reviews before it is used.

    **Analogy:** vibe coding is asking a builder for "a nice shed" and seeing what appears;
    spec-driven development is giving them a drawing, a materials list and an inspection
    checklist.

    **Why you care:** vibe coding is fine for a throwaway prototype on fictional data. Anything
    that touches real data, real users or official figures needs a spec, tests and human review.
