??? info "Know the Term: Coding agents"
    A **coding agent** is an AI assistant that does more than suggest the next line of code. Given
    a task in plain language, it reads the files in a project, plans changes, edits several files,
    runs commands such as the tests, reads the results and tries again until the task is done or it
    gets stuck. Examples as of 2026 include Claude Code, GitHub Copilot's agent mode, Cursor's agent
    and OpenAI's Codex. The simpler kind of assistant, **autocomplete**, only suggests the next few
    lines while you type and leaves every decision to you.

    **Analogy:** autocomplete is a colleague finishing your sentences; a coding agent is a junior
    developer you hand a ticket to, who comes back later with a set of changes for you to review.

    **Why you care:** a coding agent can produce in minutes what used to take a day, but you are
    still accountable for every line it writes. Clear specifications, tests and careful review
    are what make its speed safe.
